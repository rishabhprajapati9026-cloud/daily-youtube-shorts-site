# Privacy Policy

Daily YouTube Shorts is a personal automation project.

## Google and YouTube data
When authorized, the application uses Google's OAuth system and the YouTube Data API to upload videos to the owner's YouTube channel. It does not sell Google user data.

## Storage and processing
OAuth credentials are stored in encrypted GitHub Actions secrets. Generated scripts, video files, and workflow logs may be processed by GitHub Actions. Text-generation requests are sent to the configured Gemini API.

## Sharing
The application does not intentionally sell or share Google user data for advertising. Data is processed only as necessary to operate the application and its configured services.

## Revoking access
The channel owner can revoke the application's Google account access in their Google Account security settings.

## Contact
Contact the developer using the support email displayed on the application's Google consent screen.
